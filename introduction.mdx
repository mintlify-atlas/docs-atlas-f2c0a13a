## Welcome aboard

**nvim-luffy** is a modern, modular Neovim configuration that brings together the best plugins and practices in the Neovim ecosystem. Named after the legendary pirate Monkey D. Luffy from One Piece, this configuration will help you navigate the Grand Line of code with speed and style.

Every time you open Neovim, you're greeted with beautiful ASCII art of Luffy himself, reminding you that "Maybe the One Piece was the commits you made along the way."

## Key features

<CardGroup cols={2}>
  <Card title="Lazy.nvim plugin manager" icon="plug">
    Fast, modern plugin management with automatic lazy-loading for optimal startup time
  </Card>
  
  <Card title="Modular architecture" icon="boxes-stacked">
    Clean Lua structure under `lua/leyland/` with separated concerns for core config and plugins
  </Card>
  
  <Card title="LSP & intelligent completion" icon="code">
    Mason-managed LSP servers with nvim-cmp for autocompletion across 10+ languages
  </Card>
  
  <Card title="Powerful navigation" icon="compass">
    Telescope for fuzzy finding and Harpoon for lightning-fast file switching
  </Card>
  
  <Card title="Beautiful themes" icon="palette">
    Pre-configured with 6 stunning themes including Catppuccin, Tokyo Night, and Rose Pine
  </Card>
  
  <Card title="Git integration" icon="git-alt">
    Neogit and Diffview for seamless version control workflows
  </Card>
</CardGroup>

## What's included

<AccordionGroup>
  <Accordion title="Core configuration">
    - **Options**: Sensible defaults with relative line numbers, smart indentation, and system clipboard integration
    - **Keymaps**: Leader key (Space) with intuitive bindings for window management and buffers
    - **Autocommands**: Automatic formatting and file-type specific behaviors
  </Accordion>
  
  <Accordion title="Editor enhancements">
    - **Treesitter**: Advanced syntax highlighting for 25+ languages
    - **Flash.nvim**: Fast cursor navigation with search labels
    - **Auto-pairs**: Automatic bracket and quote pairing
    - **nvim-tree**: File explorer with icons
  </Accordion>
  
  <Accordion title="Development tools">
    - **LSP**: Language servers for TypeScript, Python, Lua, HTML, CSS, Tailwind, and more
    - **Formatting**: Prettier, Stylua, Black, and ESLint integration
    - **Trouble**: Beautiful diagnostics list
    - **Todo comments**: Highlight and search TODO, FIXME, NOTE comments
  </Accordion>
  
  <Accordion title="UI & aesthetics">
    - **Alpha.nvim**: Custom Luffy ASCII art dashboard
    - **Multiple colorschemes**: Bamboo (default), Catppuccin, Tokyo Night, Rose Pine, Modus, OneDark
    - **Minimal statusline**: Clean winbar showing file info without clutter
    - **Snacks.nvim**: Additional UI enhancements
  </Accordion>
</AccordionGroup>

<Note>
  The configuration sets the leader key to **Space**, making all custom keybindings start with `<Space>`. For example, `<Space><Space>` opens the file finder.
</Note>

## Philosophy

nvim-luffy is built on three core principles:

1. **Performance first**: Lazy-loading plugins and minimal startup time
2. **Developer experience**: Intuitive keybindings and powerful tools at your fingertips
3. **Aesthetics matter**: A beautiful editor makes coding more enjoyable

Whether you're a seasoned Neovim user or just starting your journey, nvim-luffy provides a solid foundation that you can build upon. The modular structure makes it easy to add, remove, or customize plugins to fit your workflow.

## Complete plugin list

Here are all plugins installed in nvim-luffy:

- **nvim-cmp** - Autocompletion engine with LSP support

### Navigation

- **Telescope** - Fuzzy finder for files, text, and more
- **telescope-fzf-native** - Native FZF sorter for better performance
- **Harpoon** - Quick file navigation and marking
- **flash.nvim** - Jump to any location with search labels

- **alpha-nvim** - Customizable startup dashboard with Luffy ASCII art

- **catppuccin** - Soothing pastel colorscheme

- **rose-pine** - Low-contrast colorscheme

- **onedark.nvim** - Atom's One Dark theme

### LSP & development

- **nvim-lspconfig** - LSP configuration framework

- **mason-lspconfig** - Bridge between mason and lspconfig

- **lazydev.nvim** - Lua development for Neovim
- **cmp-nvim-lsp** - LSP completion source
- **nvim-lsp-file-operations** - File operations via LSP

### Git integration

- **neogit** - Magit-inspired git interface
- **diffview.nvim** - Cycle through diffs for files or commits

### Utilities

- **plenary.nvim** - Lua utility functions (required dependency)
- **vim-tmux-navigator** - Seamless tmux and split navigation
- **snacks.nvim** - Collection of small QoL plugins
- **trouble.nvim** - Pretty list for diagnostics and more
- **fzf-lua** - Alternative fuzzy finder
- **mini.pick** - Minimal picker utility

## Plugin manager configuration

Lazy.nvim is configured to load plugins efficiently:

```lua
-- Bootstrap lazy.nvim
local lazypath = vim.fn.stdpath("data") .. "/lazy/lazy.nvim"
if not vim.loop.fs_stat(lazypath) then
  vim.fn.system({
    "git",
    "clone",
    "--filter=blob:none",
    "https://github.com/folke/lazy.nvim.git",
    "--branch=stable",
    lazypath,
  })
end
vim.opt.rtp:prepend(lazypath)

-- Load all plugins from lua/leyland/plugins/
require("lazy").setup({{ import = "leyland.plugins" }})
```

<Info>
Plugins are lazy-loaded using events like `BufReadPre`, `InsertEnter`, and `VimEnter` to keep startup times fast.
</Info>

## Managing plugins

<AccordionGroup>
  <Accordion title="Install new plugins">
    Add a new plugin by creating a file in `lua/leyland/plugins/` that returns a table:

    ```lua
    return {
      "author/plugin-name",
      event = "BufReadPre",
      config = function()
        -- Plugin configuration
      end,
    }
    ```

    Lazy.nvim will automatically detect and install it on next startup.
  </Accordion>

  <Accordion title="Update plugins">
    Use the `:Lazy` command to open the plugin manager UI:

    - Press `U` to update all plugins
    - Press `S` to sync (clean, install, and update)
    - Press `X` to clear finished tasks
    - Press `?` to see all keymaps
  </Accordion>

  <Accordion title="Remove plugins">
    Delete or comment out the plugin file in `lua/leyland/plugins/`, then run `:Lazy clean` to remove unused plugins.
  </Accordion>

  <Accordion title="View plugin status">
    Run `:Lazy` to see:
    - Installed plugins
    - Load times
    - Lazy-loading status
    - Git commit information
  </Accordion>
</AccordionGroup>

## Performance

Lazy.nvim provides excellent startup performance through:

- **Lazy loading** - Plugins load only when needed
- **Byte compilation** - Lua files are compiled to bytecode
- **Automatic caching** - Module loading is optimized
- **Async operations** - Plugin updates don't block the UI

You can check startup time with:

```bash
nvim --startuptime startup.log
```

<Tip>
Most plugins are event-driven and won't load until you actually use them, keeping your startup time minimal.
</Tip>
